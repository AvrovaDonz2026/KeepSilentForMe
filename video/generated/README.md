## 重试顺序

1. 逐条重新上传 `manifest.json` 指定的 `firstFrame`，在任务日志中记录文件名；有
   `lastFrame` 的结局同时核对末帧。
2. 先用单场景备选提示词重跑：`V1_pass_single_room`、`V2_out_creature_focus`、
   `V3_out_door_lock`、`V4_perform_stack`、`V4_refuse_cable`。
3. 生成后再次用 `ffprobe` 和三点抽帧检查。只有首帧正确、房间不漂移、没有可读文字/UI
   的版本才进入 Demo；跨章节切换由 HTML 页面完成。

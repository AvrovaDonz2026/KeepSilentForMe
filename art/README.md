# 美术资产目录

`art/` 根目录只保留当前运行时资产。历史批次和旧生成入口位于
[`../archive/art-v1/`](../archive/art-v1/)，不会被 Demo 或桌面版自动加载。

## 当前入口

| 路径 | 用途 |
| --- | --- |
| `bg/` | 仍由 V4 旧 manifest 和整页生成脚本引用的兼容背景源 |
| [`v4/playable/`](v4/playable/) | 55 件透明角色、NPC、表情、消音体、FX、UI 与运行时 manifest |
| [`v4/scenes/`](v4/scenes/) | 13 张整页场景/结局页、页面绑定、生成脚本和校验器 |

运行时只从两个 V4 manifest 读取资源。透明叙事层仍保留作源文件和未来变体，当前 Demo
不在整页场景上叠加它们。
